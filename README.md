# ProFit Growth Audit

**Live → https://eddieatadapty.github.io/profit-flow-rebuild/**

Five ideas to turn more ProFit users into subscribers, each built into a clickable version of ProFit's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | A first workout before the price | +10–20% CR to purchase |
| 02 | Name their answer on the paywall | +10–15% CR to purchase |
| 03 | Put your Yearly Plan on the paywall | +10–20% ARPU |
| 04 | Proof on the screen where they pay | +5–10% CR to purchase |
| 05 | Catch the people who close it | +5–10% CR to purchase |

Every price, rating and feature comes from ProFit's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for ProFit. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
